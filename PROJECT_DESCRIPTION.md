# Трекер Расходов - Проектная Работа

## 📋 Описание Проекта

**Трекер Расходов** - веб-приложение для учета личных финансов, которое позволяет пользователям отслеживать свои доходы и расходы, анализировать финансовые привычки и планировать бюджет.

## 🎯 Цель Проекта

Создать удобное и функциональное приложение для управления личными финансами с возможностью:
- Учета всех финансовых транзакций
- Категоризации расходов и доходов
- Визуализации данных через графики и отчеты
- Анализа финансового состояния за разные периоды

## 👥 Целевая Аудитория

- Студенты, желающие контролировать свои расходы
- Работающие люди для планирования бюджета
- Семьи для учета семейного бюджета
- Любой человек, заботящийся о финансовой грамотности

## ⚙️ Основной Функционал

### 1. Управление Пользователями
- **Регистрация и авторизация**
  - Email и пароль
  - Подтверждение email (опционально)
- **Профиль пользователя**
  - Редактирование личных данных
  - Смена пароля
  - Установка валюты по умолчанию

### 2. Управление Категориями
- **Категории расходов**
  - Продукты питания
  - Транспорт
  - Жилье (аренда, коммунальные услуги)
  - Развлечения
  - Здоровье и медицина
  - Одежда
  - Образование
  - Прочее
- **Категории доходов**
  - Зарплата
  - Фриланс
  - Инвестиции
  - Подарки
  - Прочее
- **Кастомные категории**
  - Пользователь может создавать свои категории
  - Выбор цвета и иконки для категории

### 3. Управление Транзакциями
- **Добавление транзакции**
  - Тип: доход/расход
  - Сумма
  - Категория
  - Дата
  - Описание (необязательно)
  - Теги (необязательно)
- **Просмотр транзакций**
  - Список всех транзакций
  - Фильтрация по:
    - Типу (доход/расход)
    - Категории
    - Периоду (день/неделя/месяц/год/произвольный)
    - Тегам
  - Сортировка по дате, сумме
  - Поиск по описанию
- **Редактирование и удаление**
  - Изменение любых полей транзакции
  - Мягкое удаление (архивация)

### 4. Аналитика и Отчеты
- **Dashboard (Панель инструментов)**
  - Общий баланс
  - Доходы за текущий месяц
  - Расходы за текущий месяц
  - Динамика по месяцам
- **Графики**
  - Круговая диаграмма расходов по категориям
  - Столбчатая диаграмма доходов/расходов по месяцам
  - Линейный график изменения баланса
- **Детальные отчеты**
  - Отчет по категориям за период
  - Сравнение периодов (месяц к месяцу)
  - Топ категорий расходов
  - Средний чек по категориям

### 5. Бюджет
- **Планирование бюджета**
  - Установка лимита на категорию
  - Период (месяц/год)
  - Уведомления при превышении (опционально)
- **Отслеживание выполнения бюджета**
  - Процент использования бюджета
  - Визуальные индикаторы (прогресс-бар)
  - Предупреждения при приближении к лимиту

### 6. Экспорт Данных
- **Экспорт в Excel/CSV**
  - Все транзакции
  - Транзакции за период
  - Отчеты
- **Экспорт графиков** (опционально)
  - PNG/PDF формат

## 📝 API Endpoints (Примеры)

### Authentication
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход
- `POST /api/auth/refresh` - Обновление токена

### Categories
- `GET /api/categories` - Получить все категории
- `POST /api/categories` - Создать категорию
- `PUT /api/categories/{id}` - Обновить категорию
- `DELETE /api/categories/{id}` - Удалить категорию

### Transactions
- `GET /api/transactions` - Получить транзакции (с фильтрами)
- `GET /api/transactions/{id}` - Получить транзакцию
- `POST /api/transactions` - Создать транзакцию
- `PUT /api/transactions/{id}` - Обновить транзакцию
- `DELETE /api/transactions/{id}` - Удалить транзакцию
- `GET /api/transactions/export` - Экспорт в Excel

### Analytics
- `GET /api/analytics/summary` - Общая статистика
- `GET /api/analytics/by-category` - По категориям
- `GET /api/analytics/by-period` - По периодам

### Budget
- `GET /api/budgets` - Получить все бюджеты
- `POST /api/budgets` - Создать бюджет
- `PUT /api/budgets/{id}` - Обновить бюджет
- `DELETE /api/budgets/{id}` - Удалить бюджет
- `GET /api/budgets/{id}/status` - Статус выполнения
